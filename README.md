# BlockLand India

A browser block-building sandbox set in northern India, with a BSL-inspired shader pipeline.
Pure static files (HTML, CSS, JS). No build step, no dependencies. Needs a browser with WebGL2.

## The map (stylised, not to scale)

- **Himalayas** along the north: snow peaks, rock, pine forest
- **Kashmir:** Dal Lake with houseboats and shikaras, chinar trees, tulip garden, terraced Mughal garden, Shankaracharya Temple
- **Himachal Pradesh:** McLeod Ganj (Tibetan temple, prayer flags), Shimla Ridge (Christ Church, Mall Road), Manali (Hadimba Temple, Beas river), Spiti (Key Monastery), Chandratal lake
- **Delhi:** India Gate with canals, Red Fort, Qutub Minar
- **Agra:** Taj Mahal with garden, canals, mosque, gateway and four minarets, beside the Yamuna
- **Jaipur:** walled pink city, Hawa Mahal, Jantar Mantar, Amber Fort, Jal Mahal
- **Udaipur:** Lake Pichola, Lake Palace, Jag Mandir, City Palace, Monsoon Palace
- **Villages** in every region: Himalayan, Spiti, Kashmiri, Rajasthani and plains villages with wells, lamp posts and fields

Every structure is generated by code in `js/world.js`. No third-party maps or assets are used.

## Shaders

Sun and moon shadows, baked ambient occlusion, bloom, god rays, animated reflective water, swaying leaves,
procedural clouds and stars, day/night cycle, marble and gold sheen, ACES tone mapping.
Presets: Balanced, Cinematic, Vivid, Performance.

## Controls

WASD move, Space jump (tap twice to fly), Ctrl sprint, Shift fly down, left click break, right click place,
1-0 or wheel pick slot, Q/E change the block in the selected slot, T day/night cycle, V shadows, B bloom, R back to spawn.

## Deploy on GitHub Pages

1. Create a repository and upload everything from this folder to the root.
2. Settings > Pages > Deploy from a branch > `main` and `/ (root)` > Save.
3. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.

Netlify, Vercel and Cloudflare Pages also work with no build command.

## Files

- `index.html`, `style.css`: page, menu, HUD
- `js/world.js`: terrain, landmarks, villages
- `js/main.js`: renderer, shaders, player
